## 项目简介

**形理书院（Xingli Academy）** 是面向传统文化爱好者与初学者的互动式教学网站，以中国传统风水学中的**形势、理气、二十四山、九宫飞星和排龙诀**为学习主线，结合古建筑、历史图版、方位工具与情境练习，帮助学习者循序渐进地理解相关概念与推演规则。

网站以沉浸式阅读和直观操作为主要交互方式，支持在浏览器中直接使用。当前版本为 **V4.0 沉浸式教学版**，无需注册账户或部署后端服务。

> **研究立场**：本项目以传统建筑文化、文献研究及术数史为学习对象。术数中的吉凶判断缺乏充分科学实证，不能用于替代建筑设计、工程安全、健康、财务等专业判断。

## 核心功能

| 功能模块 | 当前实现 | 学习价值 |
| :--- | :--- | :--- |
| **系统课程** | 6个阶段、36节课程，包含讲义、图解与操作指导 | 由基础概念逐步进入专业专题 |
| **课内练习** | 每课3题，共108道题，提供即时反馈 | 检查理解程度，巩固重点概念 |
| **可视化教学** | 课程矢量图、历史资料图、实景摄影及观察任务 | 将抽象的方位知识转化为可观察的内容 |
| **二十四山罗盘** | 方位角输入、15°山位识别、坐向对应展示 | 练习方位识读和坐向换算 |
| **玄空飞星实验室** | 流年九宫、运盘、山盘、向盘的分层教学演算 | 理解指定传统规则下的排盘步骤 |
| **案例研习** | 30个案例，其中4个真实文化遗产案例、26个模拟实训 | 学习观察环境、分析图纸与核对依据 |
| **排龙诀专题** | 原始排龙图拆解、术语说明与推演依据审查 | 了解排龙法的结构及流派差异 |
| **学习档案** | 课程进度、笔记、本地保存及手动备份恢复 | 延续个人学习过程 |
| **沉浸式界面** | 专注阅读、响应式布局、课程目录和图片放大 | 兼容桌面和移动端学习 |

> 飞星实验室以常见的**玄空下卦教学规则**为主，未完整覆盖替卦、兼向与所有流派差异；排龙诀在缺乏可靠起排依据时不提供确定的吉凶计算结果。

## 课程体系

全部36节课程按照「认识概念 → 学会读图 → 理解规则 → 动手推演 → 分析案例」的顺序组织：

| 阶段 | 课程范围 | 学习主题 | 阶段目标 |
| :---: | :---: | :--- | :--- |
| 01 基础入门 | 第01至06课 | 阴阳五行、八卦、天干地支、二十四山 | 建立传统方位和术语基础 |
| 02 形势与环境 | 第07至12课 | 龙、穴、砂、水、向与场地观察 | 学习描述地形、建筑和周边环境 |
| 03 理气与九宫 | 第13至18课 | 河图洛书、九宫、九星、三元九运 | 理解传统时间与空间框架 |
| 04 玄空飞星 | 第19至24课 | 运盘、山盘、向盘及推演方法 | 按给定规则完成基础教学排盘 |
| 05 排龙诀专题 | 第25至30课 | 来龙、阴阳顺逆、九星与排龙图 | 识读排龙材料并辨别推演依据 |
| 06 案例与研习 | 第31至36课 | 古建筑、聚落、住宅和办公场景 | 将观察、资料核验与练习结合 |

### 推荐学习方式

1. **先学原理**：阅读本课讲义，了解概念的历史语境与使用条件。
2. **再看图解**：对照高清资料图、专业矢量图，完成观察任务。
3. **跟随操作**：在罗盘、九宫或案例工具中复现演算步骤。
4. **独立练习**：完成课末测验，并记录自己的疑问与判断依据。
5. **定期复盘**：用模拟案例检验是否能脱离提示完成操作。

## 案例与资料

项目将案例明确划分为两类，避免把演示参数误认为真实建筑测量数据。

**真实建筑研习（4例）**

* 安徽宏村：传统聚落、建筑与水系关系。
* 北京中轴线：城市空间秩序与方位组织。
* 福建土楼：建筑形制与聚落环境。
* 苏州园林：空间层次、建筑与景观组合。

相关案例引用公开资料与摄影图像，用于建筑历史和空间文化观察。历史建筑的形态与选址原则，不能单独证明术数吉凶的有效性。

**模拟情境实训（26例）**

提供用于教学的住宅、办公建筑、合院等情境及示例参数，练习方位判断、九宫划分、条件核对和分步分析。**模拟参数均为教学设定，不代表真实场地测量。**

部分实景照片和历史图版由第三方公开资料站点提供，网站保留图像来源或许可信息，并在加载失败时展示备用矢量图解。

## 快速开始

### 方式一：直接在线学习

访问 [形理书院在线网站](https://scorpion-z.github.io/xingli-academy/)。

网站采用 GitHub Pages 静态托管，主要教学功能不依赖后端服务。

### 方式二：在本地运行

```bash
git clone https://github.com/Scorpion-Z/xingli-academy.git
cd xingli-academy
```

使用 Chrome、Edge 或 Safari 打开目录中的 `index.html` 即可。无需安装 Node.js、Python 或数据库。

核心课程、测验、矢量图和模拟训练可离线使用；部分实景摄影与历史图版需要联网加载。

### 方式三：自行部署 GitHub Pages

1. 将仓库克隆或 Fork 到自己的 GitHub 账号。
2. 打开 **Settings → Pages**。
3. 选择 **Deploy from a branch**。
4. 分支选择 `main`，目录选择 `/(root)`，保存。
5. 在 Pages 页面查看 GitHub 提供的实际访问地址。

仓库根目录的 `.nojekyll` 用于关闭默认 Jekyll 处理流程。

## 技术实现

当前发布仓库采用**单文件静态网站**结构。CSS、JavaScript、课程文本、测验、SVG专业图解和部分媒体内容内嵌在 `index.html` 中，便于直接打开和在 GitHub Pages 部署。

* **前端**：原生 HTML5、CSS3、JavaScript。
* **交互图解**：SVG 矢量绘制与浏览器端计算。
* **内容展示**：响应式布局、可切换课程与图像研习。
* **持久化**：浏览器 `localStorage`，支持人工导出与导入学习档案。
* **图像资料**：部分摄影及历史图版通过联网访问外部资源。

当前仓库结构：

```text
xingli-academy/
├── index.html     # V4.0 网站及教学功能
├── README.md      # 项目说明与使用指南
└── .nojekyll      # GitHub Pages 静态部署配置
```

## 数据与隐私

* 当前版本无需注册和登录，不设自建的用户账户系统。
* 学习进度与笔记主要保存在**当前浏览器的本地存储**中。
* 更换浏览器、设备、网址或清除浏览器数据后，记录可能无法自动恢复；请提前通过网站导出学习档案。
* 网站会从第三方服务器加载部分照片与历史图版；这些资源提供方可能收到正常的网络访问请求。
* 当前**没有跨设备自动同步**功能。

## 常见问题

<details>
<summary><strong>需要购买服务器或安装开发环境吗？</strong></summary>

不需要。访问者直接打开网站即可；站点发布可以使用免费的 GitHub Pages。只有需要修改源码时，才需要选择适合自己的开发工具。

</details>

<details>
<summary><strong>为什么部分照片没有显示？</strong></summary>

部分资料图托管在第三方图片服务上，可能受到网络连接、资源变更或访问策略影响。网站会显示备用矢量图，但图像出处仍建议在原始资料页核实。

</details>

<details>
<summary><strong>换电脑后为什么学习进度消失了？</strong></summary>

当前进度默认保存在原浏览器的 `localStorage` 中。请在原设备导出学习档案，再在新设备导入并核对恢复结果。

</details>

<details>
<summary><strong>可以用网站的排盘结果判断住宅吉凶吗？</strong></summary>

不建议。相关工具服务于传统术数规则的学习与复核，不具备预测健康、财富或建筑安全的科学效力。

</details>
