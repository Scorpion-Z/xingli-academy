## 关于这个项目

最近开始系统了解中国传统风水文化，对二十四山、九宫飞星和排龙诀等内容比较感兴趣。学习过程中需要频繁对照图解、查看方位、复核推演步骤，因此尝试把资料和学习笔记整理成一个可以交互操作的网站。

我目前仍是初学者，网站内容也在持续整理和校对。开发上采用 **Vibe Coding** 的方式：由我提出需求、整理学习内容、体验功能并反馈问题，借助 AI 完成代码编写、图解制作和交互实现。

项目从一个简单的学习页面逐步迭代到了 V4.0。定位是个人学习和兴趣交流，欢迎讨论，也欢迎指出内容中的错误。

## 目前有哪些功能

| 模块 | 功能 |
| --- | --- |

| 交互罗盘 | 二十四山方位、角度区间、坐向关系的查询与练习 |
| 飞星实验室 | 流年九宫，以及常见玄空下卦规则下的教学推演 |
| 案例研习 | 30 个案例，包含 4 个真实建筑文化案例和 26 个模拟练习 |
| 随堂测验 | 108 道课内练习，便于边学边检查 |
| 图像资料 | 传统图版、建筑实景、矢量图解和观察任务 |
| 学习记录 | 在浏览器本地保存进度和笔记，支持手动导出与恢复 |

## 课程内容

| 学习阶段 | 主要内容 |
| --- | --- |
| 01 基础入门 | 阴阳五行、八卦、天干地支、二十四山 |
| 02 形势观察 | 龙、穴、砂、水、向及建筑环境 |
| 03 理气基础 | 河图洛书、九宫、九星、三元九运 |
| 04 玄空飞星 | 运盘、山盘、向盘及基础推演 |
| 05 排龙诀 | 来龙、阴阳顺逆、九星及排龙图 |
| 06 综合案例 | 传统建筑、古村落、住宅和办公场景 |

学习顺序按自己的理解组织，后续会结合资料核对和实际使用继续调整。

## 如何使用

可以直接访问 **[形理书院在线版](https://scorpion-z.github.io/xingli-academy/)**，支持桌面和手机浏览器。

也可以下载到本地：

```bash
git clone https://github.com/Scorpion-Z/xingli-academy.git
cd xingli-academy
```

使用 Chrome、Edge 或 Safari 打开 `index.html` 即可。目前采用单文件 HTML、CSS 和 JavaScript 实现，不需要配置服务器或安装 Node.js。

部分建筑照片和历史图版需要联网加载；学习记录保存在当前浏览器中，更换设备时可以手动导出、导入。

## 补充说明

这是一个个人学习项目，其中涉及的传统术数解释主要用于文化研究和规则学习。吉凶、财运等说法缺乏充分的科学实证，不建议将相关推演作为建筑安全、健康、财务等事项的决策依据。

部分照片与历史资料来自公开资源，使用时仍需遵守原始来源的版权与许可要求。如果发现引用或课程内容有问题，欢迎通过 [Issues](https://github.com/Scorpion-Z/xingli-academy/issues) 反馈。
