## 为什么做这个？

起因很简单：我偶然看到一张「排龙诀」的图，里面的二十四山、九星、来龙方位看着挺有意思，但很多地方看不明白。

索性就想：**能不能做一个自己也看得懂、还能动手操作的学习网站？**

我自己也是初学者。这里的内容是我一边查资料、一边向 AI 提问、一边整理出来的，肯定还有不少需要补充和纠正的地方。

网站主要用 **Vibe Coding** 的方式完成：我负责提想法、尝试使用、找问题和调整方向，AI 帮我写代码、制作页面、实现交互。从最开始一个小页面折腾到了现在的 V4.0，纯属兴趣驱动。

## 里面都有些什么？

| 内容 | 目前有的功能 |
| --- | --- |
| 📖 系统课程 | 6个阶段、36节课，从基础概念学到玄空飞星和排龙诀 |
| 🧭 二十四山罗盘 | 输入角度，查看方位、山位和坐向 |
| 🔢 飞星实验室 | 流年九宫和常见玄空下卦的教学演算 |
| 🏡 案例馆 | 30个案例，包括4个真实建筑研习、26个模拟练习 |
| ✍️ 随堂练习 | 108道课内题，边学边测 |
| 🖼️ 图像研习 | 历史图版、建筑实景、专业矢量图与观察问题 |
| 💾 学习笔记 | 进度和笔记保存在本地浏览器，支持手动备份 |

排盘工具主要帮助理解传统规则，不同流派的算法可能有区别，特殊排法也还没有全部实现。

## 怎么运行？

想省事，直接打开 [在线网站](https://scorpion-z.github.io/xingli-academy/) 就行，电脑和手机浏览器都能用。

也可以留一份在自己的电脑上：

```bash
git clone https://github.com/Scorpion-Z/xingli-academy.git
cd xingli-academy
```

然后用 Chrome、Edge 或 Safari 打开 `index.html`。目前是单文件 HTML 网站，没有数据库，不用安装 Node.js。

少量实景照片会联网加载，断网时会显示备用图解。

## 学习路线

| 阶段 | 学什么 |
| --- | --- |
| 01 入门 | 阴阳五行、八卦、天干地支、二十四山 |
| 02 看形势 | 龙、穴、砂、水、向，认识地形和环境 |
| 03 理气基础 | 河图洛书、九宫、九星、三元九运 |
| 04 玄空飞星 | 运盘、山盘、向盘和基础推演 |
| 05 排龙诀 | 来龙、阴阳顺逆、九星与排龙图 |
| 06 看案例 | 古村落、建筑、住宅和办公场景 |

这个顺序也是我给自己安排的学习路线。如果哪一节讲得不清楚，欢迎指出来。

## 一点说明

我主要是抱着学习传统文化、了解建筑和空间知识的心态做这个网站。**传统术数里涉及的吉凶、财运等说法缺乏充分的科学证据，别把网站里的结论当成建筑安全、健康或其他专业判断。**

图片和资料有些来自公开馆藏与摄影网站，具体使用许可请以原始来源为准。如果发现图文引用不妥或者知识讲错了，欢迎通过 [Issues](https://github.com/Scorpion-Z/xingli-academy/issues) 告诉我。

仓库目前还没有单独设置开源许可证，先放出来分享和交流。
