## 项目介绍

形理书院是一个关于中国传统风水文化的个人学习项目，围绕二十四山、玄空飞星、排龙诀及传统建筑空间，整合课程、图解、案例与交互工具，用于资料研读和规则推演。

项目采用 **Vibe Coding** 方式开发，借助 AI 完成页面设计、交互功能和计算模块，并根据学习和使用过程持续迭代。相关资料与算法仍在校核和完善，欢迎交流与勘误。

**本分支版本：V5.1.0**。补齐学习档案恢复、流年入口及飞星独立练习；线上版本以实际部署为准。

## 快速开始

### 在线访问

直接打开 [**形理书院**](https://scorpion-z.github.io/xingli-academy/)，无需登录，也无需安装软件。

### 本地运行

```bash
git clone https://github.com/Scorpion-Z/xingli-academy.git
cd xingli-academy
```

使用 Chrome、Edge 或 Safari 打开根目录的 `index.html`。

这个仓库发布的是可以直接使用的静态页面，**不需要 Node.js、数据库或后端服务**。部署使用 GitHub Pages，根目录包含 `index.html` 和 `.nojekyll`。

## 开发与验证

直接使用网站不需要 Node.js。维护源码时使用 Node.js 20 或更高版本，无需安装依赖：

```bash
npm run build  # src → 根目录 index.html
npm run check  # 规则和数据测试 + 构建产物一致性检查
python3 -m http.server 8765 --bind 127.0.0.1
```

本地预览打开 `http://127.0.0.1:8765/`。GitHub Pages 继续发布根目录的静态文件。不要直接修改生成的 `index.html`，请修改源码后重新构建。

| 文件 | 职责 |
| --- | --- |
| `src/page.html` | 页面结构、原有样式与脚本占位符 |
| `src/core.js` | 方位、三盘、流年、项目与档案校验、练习评分 |
| `src/learning.js` | 原有课程、图解、案例、导航和学习记录 |
| `src/curriculum.js` | 第19—24课专题补充讲解与来源 |
| `src/tools.js` | 罗盘、飞星三个学习环节、户型项目交互 |
| `scripts/build.mjs` | 无依赖单文件构建 |
| `tests/core.test.cjs` | 固定算例、边界、迁移、存储失败回滚、课程完整性 |

课程页面仍保留历史版本的组织结构；本次只合并宅盘计算规则，未整体重写界面。

## 备份与恢复

- **文献 → 学习档案备份**：36课进度与检验、普通笔记、图像观察笔记、案例训练、实训完成记录和飞星独立练习草稿。格式版本为5.1，兼容原3.0学习档案。
- **工具箱 → 平面图分析 → 导出完整项目 JSON**：保存图片、北向、坐向、分析框、中心点和备注；导入同一文件可恢复项目。PNG 是成果图，不是可编辑备份。
- 学习档案导入替换文件中包含的记录。旧3.0档案未包含的图像笔记、工具实训与独立练习保持不变；导入前建议先导出当前档案。
- 新档案中的评分由当前规则重新核算；文字说明仅由学习者自检。户型图片不包含在学习档案中。
- 浏览器、网址、端口及 `file://` 本地文件可能使用不同存储空间；迁移时用上面两种 JSON 文件。

## 飞星专题练习

第19—22课采用八运180°子山午向示范，先分开运盘、山盘、向盘，再核对三层。第23课直接进入2024—2026流年对照。第24课直接进入九运90°酉山卯向独立练习，填写27个数字、2个顺逆判断和1个支持边界判断，并留下计算依据。

机器检查30项确定答案，显示需要复核的盘层与宫位；文字说明与资料来源需自行或由教师复核，练习通过不构成精通认证。

下卦起星与同元龙顺逆参考 [刘燮钧《玄空飞星的排法（四）》](https://www.cafengshuinet.com/m/show_detail.php?id=940)。本站将离山位中心超过4.5°、五黄入中及特殊起法列为未支持条件，不能据此推断所有传统流派均停算。186°仍是午山，但本工具不会套用180°盘。

流年采用2024年中宫3、逐年减1的教学循环，年份范围1900—2100；不处理具体日期和立春交接时刻。

## 学习路线

| 阶段 | 主要内容 |
| --- | --- |
| 01 基础入门 | 阴阳五行、八卦、天干地支、二十四山 |
| 02 形势观察 | 龙、穴、砂、水、向与建筑环境 |
| 03 理气基础 | 河图洛书、九宫、九星、三元九运 |
| 04 玄空飞星 | 运盘、山盘、向盘与基础推演 |
| 05 排龙专题 | 来龙、阴阳顺逆、排龙图与流派差异 |
| 06 综合研习 | 传统建筑、住宅与办公空间的观察练习 |

## 技术与数据

网站主要使用原生 **HTML、CSS、JavaScript 和 SVG**。当前线上版本将主要页面代码合并为单个 `index.html`，方便静态发布。

学习记录和户型练习项目主要保存在浏览器本地。平面图可能含有个人住宅信息，**请谨慎分享导出的 JSON 和 PNG 文件**。浏览器存储有清理或隔离的可能，重要练习建议定期导出备份。

部分历史资料与建筑摄影依赖第三方图片资源，需要联网加载，版权与使用许可以原始来源为准。
